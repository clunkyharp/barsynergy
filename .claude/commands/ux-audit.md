## Контекст проекта

- **Тип продукта:** B2B2C маркетплейс поставщиков энергии (барная/ресторанная отрасль)
- **Целевая аудитория:** владельцы и менеджеры баров/ресторанов + поставщики напитков
- **Основная цель:** заявка на поставку / регистрация бизнес-аккаунта / переписка с поставщиком
- **Ключевые сценарии:** поиск поставщика → просмотр каталога → отправка заявки → личный кабинет бизнеса → переписка
- **Платформы:** desktop + mobile (responsive Next.js)

## Направления анализа

Проанализируй по каждому из 17 направлений:

1. **Первое впечатление** — понятность продукта за 5 секунд, доверие, clarity ценностного предложения
2. **Информационная архитектура** — структура страниц, меню, дублирование, скрытые важные элементы
3. **Пользовательские сценарии** — пошаговый разбор ключевых флоу, friction points, где пользователь останавливается
4. **Навигация** — понятность, breadcrumbs, «где я нахожусь», путь назад/вперёд
5. **Визуальная иерархия** — акценты, конкуренция элементов, заметность CTA
6. **UI-дизайн** — сетка, отступы, типографика, цвета, иконки, консистентность компонентов
7. **Контент и микрокопирайтинг** — заголовки, кнопки, подсказки, сообщения об ошибках, язык пользователя
8. **Формы и ввод данных** — удобство, валидация, лишние поля, объяснения при вводе личных данных
9. **Конверсия** — основные CTA, барьеры перед целевым действием, ясность последствий клика
10. **Доверие и credibility** — соц. доказательства, прозрачность условий, элементы снижающие доверие
11. **Адаптивность и mobile UX** — размеры тап-целей, отступы, читаемость, видимость важных действий
12. **Accessibility** — контраст, focus/hover/active/error states, доступность для людей с ограничениями
13. **Ошибки, пустые состояния, edge cases** — loading, empty state, сетевые ошибки, восстановление
14. **Сравнение с конкурентами** — 3–5 аналогов, где сильнее/слабее, что адаптировать
15. **Приоритизация проблем** — таблица: Проблема / Где / Почему важно / Влияние / Критичность (High/Medium/Low) / Рекомендация / Эффект
16. **Рекомендации** — быстрые (1–3 дня) / среднесрочные / крупные продуктовые / кандидаты для A/B
17. **Итоговая оценка** — по шкале 1–10: UX / UI / Навигация / Конверсионность / Доверие / Доступность / Mobile
