| `NavLink` | default, active | default, hover, active, focus | workspace-product | `src/components/ui/nav-link.tsx` | sidebar/product navigation |
| `Input` | shared field base | default, hover, focus, disabled, invalid | all forms | `src/components/ui/input.tsx` | uses `field-styles.ts` |

| `ConsentField` | default | checked, focus, disabled, invalid | public, auth, business | `src/components/ui/consent-field.tsx` | canonical consent/data-processing block |

| `InlineAlert` | `info`, `success`, `warning`, `error`, `destructive`, `neutral`; `default`, `compact` | default, success, warning, error, destructive | all | `src/components/ui/inline-alert.tsx` | no new page-local notice shells |

| `Panel` | `default`, `elevated`, `inverse`; `sm`, `md`, `lg` padding | default | auth, workspace, helper public blocks | `src/components/ui/panel.tsx` | inset/support shell for dashboards, sidebars, cabinet rows and helper blocks inside an owned page surface |
| `EditorialShell` | branded shell | default | public-editorial, auth-acquisition | `src/components/ui/editorial-shell.tsx` | larger branded wrapper |
| `PublicContentDetailPage` | `article`, `event`, `course`, `vacancy`, `supplier`, `partner` via `data-detail-kind` | default, with facts, with sections, with primary/secondary actions, no published related items | public detail routes | `src/components/public/public-content-detail-page.tsx` | shared detail shell; routes must pass type-specific `sections` from `lib/public/content/{articles,events,education,suppliers,partners}.ts` or `modules/content/vacancies/queries.ts` |

| `GeneralSponsorCard` | `home`, `full`; `active`, `archived` state hook | default, hover, focus-within, long content, compact mobile | home sponsor feature, general sponsors page | `src/components/public/general-sponsor-card.tsx` | home variant must not render full phone/channel contact cards |
| `StatCard` | default | default | workspace-product | `src/components/ui/stat-card.tsx` | compact metric shell; used on admin and business dashboards |
| `Card` | `interactive`, `selected`, `loading`, `error` flags | hover, focus-within, selected, loading, error | all | `src/components/ui/card.tsx` | top-level or repeated grouped-content surface when item states like interactive, selected, loading or error matter |
| `SegmentedControl` | `default`, `inverse`, `compact` | default, hover, selected, disabled, focus | public forms, business flows, future toggles | `src/components/ui/segmented-control.tsx` | button-group semantics via `aria-pressed` |
| `Tabs` | controlled tab list | active, focus, disabled | product sections, settings, internal grouped content | `src/components/ui/tabs.tsx` | real tablist/tabpanel semantics |
| `Toggle` / `Switch` | pressed toggle, binary switch | on, off, focus, disabled | settings, filters, optional controls | `src/components/ui/toggle.tsx` | `Toggle` uses `aria-pressed`; `Switch` uses `role="switch"` |
| `AdminTable` | dense shell, `mobileLayout="cards"` / `scroll` | default, empty, row actions, mobile card rows | workspace-product | `src/components/ui/admin-table.tsx` | low-level table primitive; cells should pass `label` for mobile fallback |
| `DataTable` | alias family for `AdminTable` | default, empty, row actions, mobile card rows | workspace-product | `src/components/ui/data-table.tsx` | generic table import for product CRUD screens |
| `StatusBadge` | `success`, `warning`, `danger`, `neutral`, `pending` | default | workspace-product, public status metadata | `src/components/ui/status-badge.tsx` | canonical status meaning primitive |
| `Badge` | compatibility alias | default | legacy compatibility only | `src/components/ui/badge.tsx` | keep only for backward compatibility; new code should use `StatusBadge` |
| `MetaChip` | `default`, `filter`, `selected`, `inverse` | default, selected | public-editorial, filters, workspace metadata | `src/components/ui/meta-chip.tsx` | metadata/filter meaning only |
| `HighlightChip` | `hot`, `fresh`, `editor`, `category`; `surface`, `image` | default | public row/card markers | `src/components/ui/highlight-chip.tsx` | meaningful highlight markers only; use image surface over dark media |
| `AvatarFallback` | `sm`, `md` | default | public rows/cards, compact logo fallback | `src/components/ui/avatar-fallback.tsx` | canonical initials fallback when an image/logo is missing |
| `EditorialListRow` | `default`, `content`; `article`, `div` | default, hover by container context | public-editorial | `src/components/ui/editorial-list-row.tsx` | reusable row for editorial sections and index pages |
