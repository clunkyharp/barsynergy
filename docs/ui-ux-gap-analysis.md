### Партнеры

**Текущее состояние**

- Есть страница с объяснением форматов, список и форма.

**Что работает**

- Тон страницы верный.
- Уже понятно, что партнерство не сводится к одному типу сотрудничества.

**Где проседает UX**

- Пока раздел выглядит слишком общо.
- Не хватает структуры "кто может стать партнером -> какие форматы -> что получает -> как это помогает индустрии".
- Нет доказательной части: примеры форматов, типы интеграций, логика результата.

**Что менять в структуре**

- Порядок блоков:
  - hero;
  - кто может стать партнером;
  - форматы партнерства;
  - что получает партнер;
  - что получает индустрия / аудитория;
  - примеры сценариев;
  - CTA.

### Спонсоры

**Текущее состояние**

- Страница сильнее других по структуре и уже показывает пакеты и формат работы.

**Что работает**

- Здесь уже есть логика не просто списка, а отдельного B2B-предложения.
- Хорошо работают блоки "что входит" и "формат работы".

**Где проседает UX**

- Пока это один общий формат генерального спонсорства.
- Не хватает набора разных пакетов под разные задачи.

**Что менять в структуре**

- Разделить предложения на пакеты:
  - событие;
  - образовательная программа;
  - медиа-раздел;
  - сезонный спецпроект;
  - региональная инициатива.
- Для каждого пакета показывать:
  - формат присутствия;
  - точки видимости;
  - работу с аудиторией;
  - пример интеграции.

### Что уже хорошо

- Левая навигация понятная.
- Статусы и quick actions уже есть.
- Табличный паттерн читаемый.
- Формы стали лучше, чем были в ранней версии аудита: уже появились секции в create-flow.

### Что мешает админскому UX

- Не везде одинаковая зрелость между сущностями.
- Нет полноценного preview перед публикацией.
- Не хватает более сильных фильтров в списках.
- Не хватает bulk actions и более быстрой операционной модерации.
- `Категории`, `Города`, `Теги` все еще нужно довести до полноценного CRUD.
- Формы редактирования местами еще выглядят как длинные сетки полей, а не как рабочий редакторский интерфейс.

### Что менять

- Зафиксировать единый паттерн для всех сущностей:
  - список;
  - фильтры;
  - создание;
  - редактирование;
  - preview;
  - публикация / архив.
- Добавить sticky save bar для длинных форм.
- Вынести help text и системные подсказки ближе к полям.
- Для модерации заявок усилить:
  - статус;
  - комментарий модератора;
  - история изменений;
  - быстрые approve / reject.

## Аудит форм

### Что уже хорошо

- Формы уже встроены в контекст разделов, а не висят отдельно.
- Базовые поля и серверные сценарии есть.
- В админке появились секции в create-формах.

### Где UX слабый

- Валидация не везде достаточно локальна и понятна возле поля.
- Не хватает явного сохранения черновика как отдельного действия.
- Нет preview.
- На сложных формах не хватает явного деления на:
  - основное;
  - медиа;
  - SEO;
  - публикацию;
  - связи и теги.

### Что менять

- Для контентных форм использовать один порядок секций:
  - основное;
  - описание;
  - медиа;
  - связи;
  - SEO;
  - публикация.
- Для событий:
  - основное;
  - участие;
  - программа;
  - спикеры / партнеры;
  - публикация.
- Для вакансий:
  - компания;
  - вакансия;
  - условия;
  - модерация.
- Для поставщиков:
  - компания;
  - товары / услуги;
  - география и условия;
  - контакты;
  - публикация.

## Приоритеты доработки

### Приоритет 1

- Главная: показать живой контент и быстрые действия раньше.
- Образование / События / Знания: развести по разным сценариям, а не держать в одной оболочке.
- Вакансии: добавить фильтры и detail-flow.

### Приоритет 2

- Поставщики и Партнеры: усилить прикладную B2B-структуру.
- Спонсоры: разложить на несколько типов пакетов.
- Кабинет специалиста и кабинет поставщика: довести до отдельных продуктовых ролей.

### Приоритет 3

- Единый preview в админке.
- Фильтры и bulk actions в админке.
- Нормальный CRUD для категорий, городов и тегов.

## Рекомендуемая последовательность дальнейшей работы

1. Пересобрать информационную архитектуру главной.
2. Развести шаблоны разделов:
   - media;
   - education catalog;
   - event catalog;
   - jobs board;
   - suppliers directory;
   - partnership / sponsorship landing.
3. После этого приводить карточки, фильтры и detail-страницы.
4. Затем выравнивать админку под те же сущности и сценарии.
