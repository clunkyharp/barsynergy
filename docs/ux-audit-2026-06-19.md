# UX/UI Audit — BARSYNERGY — 2026-06-19

## Executive Summary

Продукт зрелый. UI-слой (токены, типографика, карточки) — сильная сторона: единый coffee-bar язык, аккуратная сетка, нет визуального мусора.

Главная нерешённая проблема — информационная архитектура и приоритет контента.

**Оценки (1–10):**
UX 7.0 · UI 8.2 · Навигация 6.5 · Конверсия 6.2 · Доверие 5.2 · A11y 7.2 · Mobile 6.8 · **Overall 6.9**

Рост относительно прошлого аудита (+0.6), потолок упирается в IA и приоритизацию контента, а не в косметику.

## Core UX Issues (системные)

### U1. Размытая таксономия venue/supplier/business
- **Где:** `business/page.tsx:25,134`, `site-header.tsx:77`
- **Что:** meta-title `/business` = «Каталог заведений», H1 = «Добавить заведение в каталог», кнопка hero «Посмотреть каталог» ведёт на `/suppliers` (поставщики, не заведения). Каталога заведений как такового нет.
- **Почему:** три сущности — заведения, поставщики, «бизнес-кабинет» — пересекаются в названиях и ссылках.
- **Изменить:** `/business` → «Разместить заведение» (лид-форма, без слова «каталог»). Согласовать nav-лейблы.

### U2. «Как это работает» доминирует над контентом на каждом заходе
- **Где:** `suppliers/page.tsx:65`, `vacancies/page.tsx:153`, `events/page.tsx:68`
- **Что:** HowItWorksSection (3–4 шага) рендерится всегда, выше листинга.
- **Изменить:** показывать HowItWorks только в prelaunch/empty-состоянии, либо свернуть в `<details>`, либо унести под листинг.

### U3. Перегрузка первого экрана главной
- **Где:** `homepage-hero.tsx:179–199`
- **Что:** hero = eyebrow + H1 (13 слов) + подзаголовок + ролевой блок (2 карточки) + строка статистики.
- **Изменить:** оставить H1 + подзаголовок + ролевой блок; статистику перенести ниже в отдельную полосу доверия.

### U4. Профиль-обзор = стопка одинаковых панелей
- **Где:** `profile/page.tsx:143–381`
- **Что:** до 8 Panel `tone="elevated"` подряд без иерархии.
- **Изменить:** 2 колонки (резюме слева, мета/настройки справа); убрать дубль «прогресс/незаполнено».

### U5. Бизнес-CTA в шапке ведёт в форму контактов
- **Где:** `site-header.tsx:237`
- **Что:** для `role === 'BUSINESS'` кнопка «Разместить вакансию» → `/contacts#contact-form`.
- **Изменить:** вести в `/business/cabinet` или на форму создания вакансии.

### U6. Desktop-навигация включается только с 1280px
- **Где:** `site-header.tsx:138` (`xl:flex`)
- **Что:** ноутбуки 1024–1280 получают мобильный гамбургер.
- **Изменить:** опустить порог до `lg` (1024).

## Core UI Issues

### V1. Асимметрия ролевых карточек hero
- **Где:** `homepage-hero.tsx:119–153`
- **Что:** «Я специалист» — 2 кнопки, «У меня компания» — одна.
- **Изменить:** добавить вторичное действие бизнес-карточке.

### V2. «Доказательство» = подсчёт самих себя
- **Где:** `homepage-hero.tsx:34–37`
- **Что:** `fallbackTrustMarkers = ['8 разделов платформы', '5 регионов СКФО']`.
- **Изменить:** реальные метрики или убрать.

### V3. Один визуальный вес у onboarding и контента
- **Где:** HowItWorksSection
- **Что:** surface-card + 2.2rem номера — тот же вес, что у контентных карточек.
- **Изменить:** снизить контраст (мельче, тоньше, муфтированный фон).

### V4. KPI-плитки кликабельны, но не выглядят
- **Где:** `profile/page.tsx:187`
- **Что:** AppLink без affordance (нет стрелки/«смотреть»).
- **Изменить:** добавить иконку-стрелку / hover-подпись.

### V5. min-h-11/тач-цели — выборочно
- **Где:** `site-header.tsx:234,242,262`
- **Что:** десктоп-CTA 40px < 44px.
- **Изменить:** мобильные дубли держать ≥44.

## Design System / Consistency

**Сильно:** единые токены (`--accent`, `--surface-*`, `--line`), Cormorant/Manrope, public-card-shell, статус-бейджи, FormField/FormSection.

**Несогласованности:**
- Эйброу дублирует title местами
- Два паттерна «шаги» — инлайновый и HowItWorksSteps
- min-h 10/11/12 без правила → зафиксировать: основной CTA 48, вторичный 44
- «Проверено» бейдж на мок-карточке — проверить соответствие
